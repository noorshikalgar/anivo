# 24 — Round 5: draw the motion

Status: plan and build, 2026-10-24. A user can send an element along an arrow and can key positions, but cannot draw the way an element moves. Motion designers expect to draw a path (After Effects: a motion path from position keys; Keynote: "Motion path" that you draw).

| # | Item |
|---|---|
| H1 | Done. **Draw a motion path**: select an element and a step, press P (or Add action › Draw a motion path…), and drag on the canvas. The element moves along the line in the step, from the playhead, with a smooth curve. The line is simplified to a few points. |
| H2 | Done. **Edit the path**: the points of a drawn path show as square dots on the selected element; drag a dot to change the path. |

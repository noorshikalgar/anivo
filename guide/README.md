# Anivo user guide

Anivo makes explainer videos from diagrams. You draw a diagram, divide it into steps, and Anivo animates the changes between the steps.

| Guide | Read it to |
|---|---|
| [1. Quick start](01-quick-start.md) | Open Anivo and make your first video in 10 minutes |
| [2. The editor](02-editor.md) | Draw, make steps, set timing, present, and export |
| [3. Voice and captions](03-voice-and-captions.md) | Add or record a voiceover, sync the steps, and make captions |
| [4. Agents](04-agents.md) | Let an AI agent make or change videos (MCP server, live editor, AI panel) |
| [5. Command line](05-command-line.md) | Use the `anivo` CLI in scripts and CI |
| [6. Self-host](06-self-host.md) | Run Anivo and the optional share server with Docker |
| [7. Embed and share](07-embed-and-share.md) | Put a video in a web page, or share a link |

The design documents are in [docs/](../README.md#read-the-documents-in-this-sequence). Read them to change Anivo itself.
